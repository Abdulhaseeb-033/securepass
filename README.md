# SecurePass — Password Generator

A modern, responsive password generator built with HTML, CSS, and Vanilla JavaScript.

## Features

- Generate passwords from 8 to 64 characters
- Customize uppercase letters, lowercase letters, numbers, and symbols
- Cryptographically secure random number generation using the Web Crypto API
- Estimated password strength indicator
- Copy passwords to the clipboard
- Input validation and helpful feedback messages
- Responsive dark-themed user interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Web Crypto API
- Clipboard API

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern browser.

For clipboard functionality, use localhost or a secure context such as HTTPS if required by your browser.

## Security Notes

Passwords are generated in the browser and are not intentionally sent to a server. The strength indicator is an estimate, not a security guarantee.
